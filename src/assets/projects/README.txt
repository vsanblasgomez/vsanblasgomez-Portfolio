Place your project screenshots/photos in this folder.

Required filenames (must match exactly):
  - src/assets/projects/watermarks.jpg
  - src/assets/projects/taskmaster.jpg
  - src/assets/projects/urban-cut.webp

Supported formats: .jpg, .jpeg, .png, .webp, .avif

Vite will:
  - Bundle the images into the production build
  - Hash filenames for cache-busting
  - Generate correct types for the imports

To rename a file, update the import in src/data/portfolio.ts.
