Place your profile photo here.

Filename (must match exactly):
  - src/assets/profile/avatar.png

Recommended specs:
  - 400 x 400 px minimum (800 x 800 for 2x retina)
  - Square aspect ratio
  - Centered face with some padding around it
  - JPG quality 85+ or WebP quality 80
  - < 200 KB after optimization

Supported formats: .jpg, .jpeg, .png, .webp

The photo is rendered as a 112 × 112 px circle in the Profile section.
Vite will hash the filename and bundle it into the production build.

To rename the file or change format, update the import in
src/sections/Profile/Profile.tsx.
