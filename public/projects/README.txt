Place your project screenshots/photos in this folder.

Required files (must match exactly):
  - public/projects/watermarks.jpg
  - public/projects/taskmaster.jpg
  - public/projects/urban-cut.jpg

Supported formats: .jpg, .jpeg, .png, .webp

If a file is missing, the image will show a broken state. You can
optionally use a different format/filename and update the paths in
src/data/portfolio.ts (search for `const watermarksImage`).
